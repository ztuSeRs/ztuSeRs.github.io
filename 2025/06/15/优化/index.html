简介

我对windows电脑进行优化，的记录；（仅仅只是推荐，无具体配置流程）

windows优化

  • 这是一个对windows的界面不太满意的师傅，可以看一下；我这几天对windows感觉到腻了，看到Yalois师傅新买的mac，被这种简约的样子直接吸引了。就想着直接转成macOS系统，但是怕直接装坏了，就直接优化一下感觉也是性价比比较高的方案了。话不多说直接上效果图；

窗口动画：

接下来一一介绍优化所用的软件；

软件介绍

MydockFinder

这是这次优化的主要软件；MyDockFinder 是一款专为 Windows 用户设计的桌面美化工具，能够将 Windows 桌面模拟成 macOS 的风格。

  • 高度仿真macOs

  • 系统级别的模糊效果（MyDockFinder 通过调用 Windows 系统的模糊效果接口来实现类似 macOS 的模糊背景效果。在 Windows 11 上，它利用 WinUI 模糊效果，支持自定义模糊强度。对于 Windows 10 1803 及以上版本，它使用高斯模糊效果，而在 Windows 7 和较老版本的 Windows 10 上，则采用 Aero 毛玻璃效果）

  • 文件和文件夹管理

  • 消息提示（这个实测QQ会跟windows的消息提醒冲突；会蹦出两个消息提示）

  • 窗口最小化

    最小化动画采用 D3D11 硬件加速渲染技术实现。这种技术可以模拟 macOS 的窗口最小化动画，提供流畅且逼真的视觉效果

  • 支持个性化设置

  • 操作简单

  • 资源占用低

  • 即时生效（无需设置完重启）

    MyDockFinder 使用 WinUI 和 GPU 渲染技术，实现流畅的动画效果和贝塞尔曲线圆角模糊。用户可以调节模糊强度，以达到理想的视觉效果

    具体的设置也是非常简洁明了，可以根据自己的想法进行定制；也有创意工坊，会有大佬发各种可爱或者整活的资源包

    设置页面：

安装的过程也很简单；在steam上就能直接下载，售价是24块钱，和wallpaper一样支持离线启动。

但是有个问题是qq的截屏会有一定的bug所以推荐一个截屏软件（支持OCR）

[Pixpin](PixPin - 强大且免费的截图贴图工具)

可以说是qq截图的平替了

Wallpaper Engine

这个软件应该大多数人都会有；不多赘述了steam价格（我买的时候好像是36）；

当然其实是有免费差不多的软件名字叫[wallhaven](Awesome Wallpapers - wallhaven.cc)

之前是有一个软件的但是现在找不到具体来源了

windows几乎靠这两个就能实现很大的优化；ps：但是终究是windows系统下对macos系统的模仿仍旧会有很多不足，只能说瑕不掩瑜。

桌宠

桌面上如果觉得太单调可以尝试一下[BongCat](ayangweb/BongoCat: 🐱 跨平台桌宠 BongoCat，为桌面增添乐趣！)这个桌宠github的项目（结合live2D，b站上也有很多模型）他能实时你的鼠标和按键，算是个简单的虚拟形象了(这个最近在活跃的更新，解决了一堆bug，还更新了一键自定义模型的功能；)

让你使用电脑的时候不孤单
